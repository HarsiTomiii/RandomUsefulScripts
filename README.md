# RandomUsefulScripts

A grab-bag of small, standalone scripts — each one solves a specific one-off problem. No shared framework or dependencies between them; just `cd` into a script's folder and read its own README for details.

## Scripts

- [MyLiveWallpapersToMP4/mlwtomp4.py](MyLiveWallpapersToMP4/README.md) — Decrypts `.mlw` live wallpaper files (from the MyLiveWallpapers app) and extracts the underlying `.mp4` video.

## Usage

Each script lives in its own folder with its own README covering requirements and usage. Check that README before running anything.
