# RandomUsefulScripts

A grab-bag of small, standalone scripts — each one solves a specific one-off problem. No shared framework or dependencies between them; just `cd` into a script's folder and read its own README for details.

## Scripts

- [MyLiveWallpapersToMP4/mlwtomp4.py](MyLiveWallpapersToMP4/README.md) — Decrypts `.mlw` live wallpaper files (from the MyLiveWallpapers app) and extracts the underlying `.mp4` video.
- [IcsToGoogleCalendar/icsToGoogleCalendar.py](IcsToGoogleCalendar/README.md) — Imports a `.ics` file as an event into Google Calendar and opens it in your browser.
- [PhilipsAndroidTVLauncher/](PhilipsAndroidTVLauncher/README.md) — A minimal home screen for a Philips Google TV with a Jellyfin "Continue watching" row (Android app).
- [TVCalibrationTool/](TVCalibrationTool/README.md) — Browser test patterns and settings checklists for an LG C6 (CachyOS PC monitor) and a Philips OLED708, plus `lgtv-pc`, a Linux companion that applies/verifies the LG's picture settings and ties the TV's power to the PC.

## Usage

Each script lives in its own folder with its own README covering requirements and usage. Check that README before running anything.
